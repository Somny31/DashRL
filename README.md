# ⚡ DashRL

**A lightweight and customizable Rocket League companion for Windows.**

DashRL is a Windows companion application designed to enhance your Rocket League sessions with real-time match tracking and customizable in-game overlays.

Track your session, display your statistics in-game and create your own overlay without requiring BakkesMod.

---

## ✨ Features

### 🎮 Live Match Tracking

View information from your current Rocket League match in real time.

- Current score
- Match timer
- Player score
- Goals
- Assists
- Saves
- Shots
- Boost

### 📊 Session Tracking

DashRL automatically tracks your session performance.

- Wins
- Losses
- Win streak
- Loss streak

Your session statistics are automatically reflected in the overlay.

---

## 🖥 In-Game Overlay

Display your session statistics directly while playing Rocket League.

Built-in overlay styles:

- Minimal
- Competitive
- Cards
- Pill
- Custom

The overlay can automatically appear while Rocket League or DashRL is active.

---

## 🎨 Custom Overlays

DashRL V2 introduces a complete custom overlay system.

Create your own overlay directly inside DashRL using the built-in visual editor.

Available elements include:

- Wins
- Losses
- Streak
- Custom text
- Containers

Each element can be customized individually.

### Customization

- Position
- Width
- Height
- Font size
- Text color
- Background color
- Border color
- Border thickness
- Corner radius
- Opacity
- Bold text
- Transparency

---

## 🖌 Overlay Editor

The custom overlay editor provides a simple visual workspace inspired by graphic design tools.

Features include:

- Drag & drop elements
- Layer management
- Element selection
- Element resizing
- Canvas resizing
- Canvas up to **400 × 400**
- Zoom controls
- Fit-to-screen
- Color palette
- Transparent backgrounds
- Live preview

Custom overlays are saved locally and can be reused whenever you want.

---

## 📍 Overlay Positioning

DashRL provides several predefined positions:

- Top Left
- Top Center
- Top Right
- Center
- Bottom Left
- Bottom Center
- Bottom Right

You can also fine-tune the overlay position using custom **X / Y offsets**.

---

## ⚙ Overlay Settings

You can customize the global overlay directly from DashRL.

- Adjustable scale
- Adjustable opacity
- Show / hide Wins
- Show / hide Losses
- Show / hide Streak
- Click-through mode
- Custom X / Y positioning

Your settings are automatically saved and restored when DashRL starts.

---

## 🚀 No BakkesMod Required

DashRL works independently and does **not require BakkesMod**.

No DLL injection, game modification or BakkesMod plugin is required.

---
